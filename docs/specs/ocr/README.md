## Общие правила исполнения

- Перед коммитом `pytest -v` зелёный целиком. Условие входа: `test_files/sample.pdf`
  и `test_files/ocr_sample.pdf` на месте (без них 5 тестов `test_pdf_core.py` падают
  ещё до любых правок) и git работает (`git status` без `dubious ownership`).
  Нет — стоп, это чинит человек.
- Сетевые тесты — маркер `@pytest.mark.live`; идут **только** при `MINERU_LIVE=1`
  (ПРАВКА #71). Ключ `MINERU_API_KEY` живёт в окружении постоянно, и на нём голый
  `pytest` молча уходил в облако и жёг квоту. Без флага — `skip` с причиной.
  Фикстурные тесты пропускаются, если нет `_test/fixtures/ocr/` (папка в `.gitignore`).
  Пропуск — через `tests/ocr_fixtures.py::require_fixture`, не самодельный.
- vlm не байт-детерминирован: сравнения с эталонами только после нормализации и
  по порогу, никогда на точное равенство строк.
- Не глотать данные. Всё, что тракт не смог разобрать или восстановил догадкой, —
  находка в отчёте. Молчаливый пропуск — худший дефект проекта.
- Тракт чинит только известные систематические артефакты. Сомнительное помечает,
  не исправляет.
- Код кроссплатформенный (Windows локально, Linux у Hermes): `pathlib`, без
  хардкода разделителей, файлы пишутся с `encoding="utf-8"`.
- Профильные привычки проекта действуют и здесь: словарные ключи — `d['key']`,
  не `.get`, когда ключ обязателен; любая проверка руками превращается в тест.
- Коммит-сообщение — дословно из спеки. Маркер `# ПРАВКА #N: …` ставится в
  докстринг/шапку нового модуля и у каждого изменённого места существующего файла.

## Общие типы и константы (фиксируются здесь, действуют для всех спек)

Файл `ocr/__init__.py`. Создаёт та из спек 02/04, что исполняется первой;
вторая файл не перезаписывает. Содержимое дословно:

```python
"""ПРАВКА #61/#63: OCR-тракт MinerU. Общие типы."""

from dataclasses import dataclass

SEVERITIES = ("critical", "warning", "info")


@dataclass(frozen=True)
class Finding:
    rule: str
    severity: str            # одно из SEVERITIES
    page: int | None         # 1-based; None — страница неизвестна
    snippet: str             # дословный фрагмент из markdown, по нему ищется место пометки
    suggestion: str | None = None
```

### Правила и их серьёзность (закрытый список)

Серьёзность правила — константа, от входа не зависит. `critical` даёт код
