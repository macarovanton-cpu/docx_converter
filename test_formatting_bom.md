# Заголовок с BOM в начале файла

Этот файл сохранён в UTF-8 с меткой порядка байтов (BOM). Строка выше должна стать полноценным заголовком H1 — синим, PT Sans Narrow, крупным. Если она отрендерилась обычным абзацем с решёткой в начале, значит BOM не срезается перед разбором markdown.

## Подзаголовок

Обычный абзац, чтобы документ не был пустым.
